## 增量范围及复现

新增 lib/visual-model.ts、VisualBusinessModelEditor 及局部 CSS、编辑器测试与交接文档。必要修改限于 State 可选模型字段、Store 统一治理适配及 business.tsx（包含 Analyst）。原导航、Shell、全局样式、原只读 Canvas 与其他已确认页面源文件保留。

保留原锁文件及依赖版本，package 版本改为 1.2.0。安装使用原 frozen-lockfile；环境包管理器在 package 版本变化后误触发依赖重装检查，最终使用已安装工具的入口重新验证，没有更换依赖或放宽安全策略：

```sh
node node_modules/typescript/bin/tsc --noEmit
node --test tests/*.test.mjs
node node_modules/vite/bin/vite.js build --config vite.portable.config.ts
node node_modules/vinext/dist/cli.js build
```

正常环境仍可使用 README 的 pnpm 脚本。ZIP 中不包含 node_modules、构建缓存、测试产生的浏览器数据或用户凭证；包含可直接本机预览的 preview-dist。

## 产品边界

仍是 localStorage 前端原型。AI 布局为本地确定性模拟；影响分析记录真实变更对象但依赖计划仍为预设工单示例；没有真实 LLM、服务端事务、多人协作、跨设备存储、生产 Runtime 或真实发布。语义/布局治理的服务端实施约束见 06-visual-model-editor.md。
